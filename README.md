# LA GYOZERÍA — FACA Challenge II Landing Page

Editorial street-food landing page and interactive financial showcase for **La Gyozería** (Madrid, 2027), built for **FACA Challenge II (ICAI — Universidad Pontificia Comillas)**.

## Live Site
- **GitHub Pages:** https://mrandy5.github.io/la-gyozeria-landing/

## Highlights
- **Neo-Brutalist Street-Food Editorial UI:** Raw rice-paper canvas (`#F5F2EB`), deep soy ink (`#111111`), vermilion chili (`#E63926`), electric yuzu (`#D9FF00`), paired with `Syne`, `Plus Jakarta Sans`, and `JetBrains Mono`.
- **Interactive Menu Filter:** All 11 menu items (Single, Menús, Packs) with weighted average ticket (`7,54 €`) and order mix.
- **Live Scenario Switcher (FACA Challenge II v3 model):** Switch between **Pessimistic**, **Base**, and **Optimistic** scenarios to update NPV, IRR, PI, Payback, and the 5-year CFFA bar chart in real time.
- **Risk, Sensitivity & Real Options:** Tornado chart of NPV drivers, Operating Leverage (`DOL = 5,42x`), and Abandon / Expand real options.
